# 🌐 Internet Systems

> Understanding the internet, one protocol at a time.

I've always wanted to document my understanding of how the internet actually works. So I started building this project: **Internet Systems**.

The goal is simple: collect, explain and visualize the technologies and protocols that make the internet work.

I know there is much more to learn, and this project is far from complete. I'll keep researching, learning and expanding it over time.

## 📖 What You'll Learn

### 🌍 Application Layer

- **HTTP / HTTPS** – How browsers communicate with web servers.
- **FTP / SFTP** – How files are transferred between devices.
- **SSH** – How to securely access remote servers.
- **SMTP** – How emails are sent across networks.
- **DNS** – How domain names are translated into IP addresses.

### 🔌 Transport Layer

- **TCP** – Reliable data transmission.
- **TCP Handshake** – How a TCP connection is established.
- **UDP** – Fast, connectionless data transmission.

### 🌐 Network Layer

- **IPv4** – How devices are addressed and identified across IP networks.

### 🔍 Tools

- **Wireshark** – Inspecting and analyzing network traffic.

Internet explained but simple

SFTP

SFTP ist ein File Transport Protocol basierend auf SSH (deshalb auch SFTP) womit man Datein auf einen Server erstellen, bearbeiten oder löschen kann!

Und dabei ist alles Verschlüsselt somit kann niemand mitlesen.

FTP

FTP ist ein File Transport Protocol womit man Datein auf einen Server erstellen, bearbeiten oder löschen kann!

jedoch leider nicht sicher. Durch eine MIT-Attack kann der gesamte Verkehr (unteranderem auch die Datei selbst) mitgelesen werden daher lieber SFTP benutzen

SSH

SSH ist eine Secure Shell wobei man auch sagen kann das es ein Remote-Server-Accsess ist.

Es ist eine Verbindung zu einem entfernten Server komplett Verschlüsselt.

Wie ist sie verschlüsselt?

Während des Verbindungsaufbau findet ein Kryptographischer Schlüsselaustausch statt.

Dabei wird ein gemeinsamer Sitzungsschlüssel abgeleitet. Mit diesem gemeinsamen Schlüssel wird die Verbindung verschlüsselt.

Das dient der Sicherheit, somit kann niemand mehr mitlesen

SMTP

SMTP steht für Simple Mail Transfer Protocol.

Es wird verwendet um E-Mails von einem Client an einen Mailserver oder zwischen Mailservern zu übertragen.

Zum Abrufen von E-Mails werden hingegen meistens IMAP oder POP3 verwendet.

TCP

TCP ist ein Protocol welches Daten überträgt.

Bevor aber Daten gesendet werden können muss ein so genannter TCP-Handshake erfolgen.

Falls dieser Erfolgreich war werden so Daten Übertragen:

Daten gesendet -> Empfangen?

Falls nein -> Erneut den fehlenden Teil senden

Quasi wie die Post, gut für Nachrichten.

TCP-Handshake

Wenn ein Nutzer eine TCP Anfrage sendet passiert folgendes:

Nutzer sendet SYN
Server antwortet mit SYN + ACK
Nutzer sendet ACK

Danach steht die Verbindung erst

*ACK = Acknowledgment, SYN = Synchronize

UDP

UDP ist ein Protocol welches Daten sendet auch wenn sie nicht ankommen.

Gut für Live-Übertragungen

HTTP

HTTP bedeutet HyperText Transfer Protocol.

Man hört es ständig und es steht in jeder URL.

HTTP wird von deinem Browser genutzt um Websiten anzuzeigen jedoch ist sie keines wegs sicher!

Alle Daten sind unverschlüsselt und durch Tools wie z.B. Wireshark sehr einfach nachzuverfolgen.

Es gibt verschiede Anfragen für Websiten / Hypertext z.B.
- GET
- POST
- DELETE

Wenn eine Browser deine Website laden will wird eine GET Anfrage gesendet welche ungefähr so aussieht: 

GET /index.html HTTP/1.1
Host: www.beispiel.de
User-Agent: Mozilla/5.0
Accept: text/html
Connection: keep-alive
index.html ist die angeforderete Ressource

Host ist die Domain von der angefragt wird

User-Agent gibt den Browser des Nutzers an

Accept gibt an welche datenformate akzeptiert werden

Connection gibt an ob die Verbindung bestehen bleibt

HTTPS

HTTPS bedeutet HyperText Transfer Protocol Secure.

Es unterscheidet sich hauptsächlich von dem Sicherheitsstandard.

Durch die Verschlüsselung der Daten ist es quasi unmöglich mehr mitzulesen.
